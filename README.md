# 🎮 Find My Number Game

A simple and interactive number guessing game developed using
**Python, Flask, HTML, and CSS**.

## 📖 About the Project

Find My Number is a web-based guessing game where the player tries
to find a randomly generated number.

The game provides feedback based on the player's guess and allows
the player to continue guessing until the correct number is found.

## ✨ Features

- 🎯 Random number generation
- 🔢 Number guessing
- 💡 Helpful feedback for guesses
- 🏆 Winning/result screen
- 🎨 Simple and attractive user interface
- 🌐 Web-based application

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
